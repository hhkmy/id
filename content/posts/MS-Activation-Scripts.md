Office 365 with Developer Account ဆိုတဲ့ Microsoft Program ပိတ်သွားတဲ့နောက်မှာတော့ Mail account တွေလည်း သုံးမရတော့သလို အခြားသော Development purpose ပေးထားတဲ့ အခြားအရာတွေပါ သုံးလို့မရဖြစ်ကုန်တော့တယ် T_T

ဒီလိုနဲ့ပဲ ဟိုကြည့်ဒီကြည့်နဲ့အတော်အဆင်ပြေတဲ့ Microsoft Activation Scripts လေးကိုတွေ့ပြီး လိုက်စမ်းကြည့်တော့ အတော်အဆင်ပြေသွားတော့တယ် xD

အခြား ထွေထွေထူးထူးတွေလုပ်နေစရာမလိုအပ်ပါပဲနဲ့ Power Sell ကို Administration Permission လေးနဲ့ ဖွင့်ပေးလိုက်မယ်ဆိုရင်တော့ အဆင်ပြေပါပြီ။ ထွေထွေထူးထူးလည်း အများကြီးလုပ်နေဖို့မလိုပါဘူး Command Line တကြောင်းထဲနဲ့ တက်လာတဲ့ Window မှာ အဆင်ပြေမှာကို ရွေးပြီးလုပ်လိုက်ရင်ရပါပြီ။ ရိုက်ရမယ့် Command လေးကတော့ အောက်က line ပါပဲ။

```bash
irm https://get.activated.win | iex
```

ပါဝင်တာတွေကတော့ Windows Activation နဲ့ Office Activation ပါပဲ။ Office အတွက်ကတော့ အစောပိုင်းမှာ တင်ထားခဲ့ဖူးတဲ့ [Activate Windows 10 Pro Permanently]({{< ref "activate-windows-10-pro-permanently.md" >}} "Activate Windows 10 Pro Permanently") ဆိုတာလေးနဲ့ အတော်ကိုအဆင်ပြေတာပါ။ ဆိုပေမယ့် ဒီနည်းလမ်းမှာလည်း Windows Activation ပါဝင်နေတာဆိုတော့ လိုအပ်တဲ့လူတွေအတွက်တော့ အဆင်ပြေမှာပါ။

အသုံးပြုပုံကတော့ Number Key တွေကို ထည့်သွင်းလိုက်ရင် သူ့ Function အလိုက် ကူးပြောင်းသွားမှာဖြစ်ပြီး သက်ဆိုင်ရာ Function ကိုအလုပ်လုပ်ပေးသွားပါလိမ့်မယ်။ ဒီထဲမှာ အခြားသော အရာတွေအနေနဲ့ကတော့ Troubleshot အပြင် Extra Office and Windows အတွက်ပါ Download လုပ်ဖို့အတွက်ပါ ဝင်တာဆိုတော့ ကိုယ်တိုင်စမ်းကြည့်လိုက်တာပိုကောင်းတယ်။

တကယ်က Content ရေးတယ်ဆိုတာထက်ကို ကိုယ့် Website ကို ပြန်ကြည့်လိုက်ရင် အချိန်မရွေး ပြန်သုံးနိုင် ပြန်လုပ်နိုင်အောင်ရေးတဲ့သဘောပါပဲ။ အခြားလူတွေ နားလည်အောင်ရေးတယ်ဆိုပေမယ့်၊ နားမလည်ရင်တော့ တတ်နိုင်တော့ဘူး 😆

ရေးရင်း စမ်းရင်းနဲ့တော့ Office လည်း Active သလို DISM လည်း Check လုပ်ရင်းနဲ့ပဲ ...

သူ့ရဲ့သဘောတရားကို နားမလည်တာကတော့ သက်ဆိုင်ရာ Activation key အလိုက် Officie Version ကလည်း ပြောင်းသွားမယ်ထင်တယ်။ သေချာတော့ မသိသေးပေမယ့် Active လုပ်ပြီး Word 365 ကို ဖွင့်လိုက်တော့ License active လုပ်ခိုင်းတာနဲ့ Accept လုပ်လိုက်ရင်းနဲ့ Actived Office ကိုရသွားတော့တာပဲ 😆
